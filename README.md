A multi-threaded Python port scanner with banner grabbing, service detection, and vulnerability risk analysis.

## 🚀 Features
- Multi-threaded scanning engine
- Banner grabbing (service fingerprinting)
- Vulnerability risk classification (LOW / MEDIUM / HIGH)
- Hacker-style CLI interface
- JSON report generation
- Risk summary analytics

## ⚙️ How to Run
python scanner.py

📦 Requirements
Python 3.x
colorama

Install dependencies:
pip install colorama
